# Mission 5: The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I deployed MinIO, an s3-compatible
object storage server, using the Docker in the KillerCoda Playground.
I made an object storage bucket named `client-photos` and
uploaded a sample file to the bucket.

## Objectives

- Differentiate Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Access the MinIO Web Console using port forwarding.
- Create an object storage bucket.
- Upload an object to the bucket.
- Document cloud storage operations using Markdown.

## Tools Used


- Docker
- MinIO
- GitHub
- Ubuntu/Linux Terminal
- KillerCoda Playground
- Web Browser
